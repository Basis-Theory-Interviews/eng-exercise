# Exercise: Pizza Ordering and Checkout

This is a language-agnostic software engineering interview exercise. You will
build a small pizza ordering application in the language and frameworks you are
most comfortable with.

The exercise is intentionally open-ended. We care more about how you break down
the problem, evaluate options, and explain tradeoffs than how much code you
produce.

## Before the interview

- Bring the IDE and development tools you normally use.
- Set up the AI tools you prefer. AI use is expected and encouraged during the
  exercise.
- Make sure you can run your chosen stack locally.

You do not need to write any code before the interview. If access to an AI tool
or a payment processor test account becomes a problem during the session, let
your interviewer know.

## During the interview

Start by walking through your design before implementing it. Explain the main
components, the order and payment flow, the boundaries you would create, and
the first useful slice you plan to build. Continue to narrate meaningful
choices or changes in direction as you work.

AI can author and implement code. You should still be able to explain what it
is doing, evaluate the result, and discuss how you would evolve the solution.

Read the complete [exercise requirements](docs/exercise.md) when the interview
begins.
